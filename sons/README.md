# Sons du Mafia

Sons générés par Yassine avec son abonnement **Suno** (outil Sounds), envoyés
par lien de partage `suno.com/s/...` dans le chat, puis découpés/compressés ici
(ffmpeg : mono 44,1 kHz, 48 kb/s, fondu de sortie) et inlinés dans
`mafia/index.html` via `python3 outils/inliner-sons.py`.

Noms de fichiers = noms de sons du jeu :
`nuit, aube, mort, sauve, vote, egalite, roles, vjoie, vsombre`.
Un son absent d'ici garde son repli synthétisé (Web Audio) dans le jeu.

- `nuit.mp3` — « Soft night wind in a narrow medina alley, distant owl » (Suno,
  10,5 s d'origine → 4,5 s, fondu 1,5 s). Source : https://suno.com/s/0iAy3EMppgAlywsM
